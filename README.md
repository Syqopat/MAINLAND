# Mainland Scripts

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

A collection of standalone Python utility scripts.

## Included Scripts
- `main.py`: Main entrypoint for general utilities.
- `mintosec.py`: Time conversion utility.

## Usage
Run the scripts using standard python commands:
```bash
python main.py
```
